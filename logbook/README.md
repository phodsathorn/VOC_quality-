# Logbook โครงการ VOC Quality

โฟลเดอร์นี้เก็บประวัติการเปลี่ยนแปลง การตัดสินใจ การตรวจสอบ และงานค้าง เพื่อให้ทีมตรวจสอบย้อนหลังและส่งต่องานได้

## ข้อบังคับ

เมื่อมีการแก้ไขโค้ด เอกสาร การตั้งค่า infrastructure/deployment หรือข้อมูลสำคัญ ต้องบันทึก log ก่อนจบงานเสมอ โดยกติกานี้ถูกระบุซ้ำใน `../AGENTS.md` สำหรับผู้ช่วยหรือ agent ที่ทำงานกับ repository นี้

ห้ามบันทึก secret ทุกชนิด เช่น password, API key, token, private key หรือ database connection string จริง

## ชื่อไฟล์

ใช้รูปแบบ:

```text
YYYY-MM-DD_หัวข้อภาษาอังกฤษแบบ-kebab-case.md
```

ตัวอย่าง: `2026-10-26_sensor-validation-and-deployment-security.md`

## โครงสร้าง log ขั้นต่ำ

```md
# YYYY-MM-DD — หัวข้องาน

## สรุป

## สิ่งที่เปลี่ยน

## เหตุผลและผลกระทบ

## การตรวจสอบ

## การตัดสินใจ/ข้อสมมติ

## งานค้างและขั้นตอนถัดไป
```

งานต่อเนื่องในวันและหัวข้อเดียวกันให้เพิ่มหัวข้อ `## อัปเดตเวลา HH:MM ICT` ในไฟล์เดิม
