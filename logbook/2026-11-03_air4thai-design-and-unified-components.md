# 2026-11-03 — Air4Thai Design Model & Unified UI Components

## สรุป
นำแนวทางการออกแบบและมาตรฐานดัชนีคุณภาพอากาศของ **Air4Thai (กรมควบคุมมลพิษ - PCD Thailand)** มาเป็นต้นแบบหลักในการแสดงผลของทั้งระบบ พร้อมสร้างชุด Reusable UI Components มาตรฐาน (`components/ui/`) เพื่อให้ทุกหน้าเรียกใช้ชิ้นส่วนเดียวกัน (ปุ่ม, การ์ด, ตัววัด KPI, แถบสเกล AQI, ป้ายสถานะ) อย่างเป็นเอกภาพและน่าเชื่อถือตามมาตรฐานราชการ

## สิ่งที่เปลี่ยน
1. **สร้างโมดูลคำนวณและข้อมูลมาตรฐาน Air4Thai (`src/utils/aqiHelper.js`)**:
   - กำหนดเกณฑ์ 5 ระดับคุณภาพอากาศของประเทศไทย:
     - 0 - 25: **ดีมาก** (ฟ้า `#00b0f0`)
     - 26 - 50: **ดี** (เขียว `#84cc16`)
     - 51 - 100: **ปานกลาง** (เหลือง `#eab308`)
     - 101 - 200: **เริ่มมีผลกระทบต่อสุขภาพ** (ส้ม `#f97316`)
     - 201 ขึ้นไป: **มีผลกระทบต่อสุขภาพ** (แดง `#ef4444`)
   - ฟังก์ชันคำนวณ AQI จากค่า PM2.5 ตามสูตรมาตรฐานของกรมควบคุมมลพิษ
2. **สร้างชุด Reusable UI Components (`src/components/ui/`)**:
   - `AqiScaleBar.jsx`: แถบสเกลแนวนอน 5 สีตรงตามแบบของเว็บไซต์ Air4Thai พร้อมตัวชี้ตำแหน่งค่าปัจจุบัน
   - `AqiBadge.jsx`: ชิปป้ายสถานะดัชนีคุณภาพอากาศระบุระดับและสีตามมาตรฐาน
   - `Button.jsx`: ปุ่มกดแบบรวมศูนย์ (Primary, Secondary, Outline, Danger, Success, Ghost) รองรับไอคอนและสถานะโหลด
   - `Card.jsx`: การ์ดคอนเทนเนอร์มาตรฐานพร้อมส่วนหัว ไอคอน และสล็อต Action
   - `StatCard.jsx`: การ์ดแสดงผลค่าเซนเซอร์/KPI พร้อมตัวเลขขนาดใหญ่ หน่วย ป้ายสถานะ และแถบ Progress
   - `PageHeader.jsx`: แถบหัวเรื่องของแต่ละหน้าพร้อมไอคอน หัวข้อย่อย และกลุ่มปุ่มการทำงาน
3. **ปรับปรุงหน้าระบบ**:
   - **`Dashboard.jsx`**: เพิ่มแถบเกณฑ์ดัชนีคุณภาพอากาศ Air4Thai พร้อมการ์ด KPI แสดงค่า AQI คำนวณจริง และปรับใช้ `PageHeader`, `StatCard`, `Button`, `Card`
   - **`Kiosk.jsx`**: เพิ่มแถบสเกล Air4Thai และเชื่อมต่อค่า PM2.5 ฝุ่นสีหน้างาน
   - **`History.jsx`**: เพิ่มแถบเปรียบเทียบมาตรฐาน Air4Thai เมื่อเลือกดูข้อมูลย้อนหลังของ PM2.5
   - **`Guide.jsx`**: เพิ่มเนื้อหาข้อมูลดัชนีคุณภาพอากาศ (AQI) และคำอธิบายสารมลพิษ 6 ชนิด พร้อมตาราง 5 ระดับตามต้นแบบ Air4Thai

## เหตุผลและผลกระทบ
- **เหตุผล**: ผู้ใช้ต้องการให้เว็บมีรูปแบบที่น่าเชื่อถือ เข้าใจง่าย ตรงตามต้นแบบของ Air4Thai และต้องการให้ปุ่มหรือส่วนประกอบต่างๆ ถูกดึงมาจาก Reusable Components แบบเดียวกันทั้งหมด
- **ผลกระทบ**: หน้าตาของเว็บไซต์ทั้งหมดมีความเป็นมืออาชีพ มีมาตรฐานสีดัชนีคุณภาพอากาศที่ตรงตามกรมควบคุมมลพิษ และโค้ดมีความเป็นระเบียบดูแลรักษาง่าย
