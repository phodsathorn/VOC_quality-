# เอกสารโครงการ

- `architecture/` — ภาพรวมระบบ E-Nose, airflow และ web platform
- `hardware/` — วงจร การต่อสาย และข้อมูล component
- `ml/` — การวิเคราะห์และออกแบบ machine learning
- `product/` — product specification, pitch และแผนอัปเกรด
- `research/reference/` — ข้อมูลเปรียบเทียบ sensor, เอกสารอ้างอิง และงานวิจัย

เอกสารประเมินและแผนงานของระบบที่กำลังใช้งานจริงอยู่ใน `../vocs-website/` เพื่อให้ใกล้กับ frontend, backend และ firmware ปัจจุบัน
