calculate How it is calculated

AQI is computed by standard piecewise linear interpolation between defined pollutant concentration breakpoints:

AQI = [(I_high - I_low) / (C_high - C_low)] × (C - C_low) + I_low
• C: Pollutant concentration value
• [C_low, C_high]: Concentration breakpoint bracket
• [I_low, I_high]: Corresponding AQI index bracket
