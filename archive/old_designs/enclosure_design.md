# 📦 การออกแบบกล่องวัดคุณภาพอากาศ (Air Quality Monitoring Enclosure Design)

> **ปรับปรุงล่าสุด:** ซิงค์โครงสร้างกล่องและอุปกรณ์ทั้งหมดให้ตรงกับ `wiring_design.md` (พัดลม 40mm 2 ตัว, ควบคุมด้วย Relay, ระบบไฟแบบจัดเต็มพร้อมวงจรป้องกัน)

## 1. หลักการออกแบบจากงานวิจัย (Research-Based Design Principles)

### 1.1 แหล่งอ้างอิง

| แหล่ง | เนื้อหาหลัก | สิ่งที่นำมาใช้ |
|---|---|---|
| **IEEE Sensors Journal** | ปริมาตรห้อง (Chamber Volume) ยิ่งเล็ก → Response Time ยิ่งเร็ว | ออกแบบ Dead Volume ให้น้อยที่สุด |
| **MDPI Sensors** | การใช้ Active Sampling ให้ค่าเสถียรกว่า Passive Diffusion | ใช้พัดลม 2 ตัว (Push-Pull) ควบคุมด้วย Relay |
| **EPA Method 5 / NFPA 33** | ตำแหน่งวัดต้องอยู่หลัง filter, ก่อนปล่อยสู่ภายนอก, ท่อตรง ≥ 8D | เลือกจุดติดตั้งในท่อ exhaust |
| **Semantic Scholar** | เซนเซอร์ MQ มี heater 200-400°C, ต้องแยกจากวงจรอื่น | แบ่งโซนร้อน/เย็นในกล่องด้วยฉนวน |

### 1.2 หลักสำคัญ 5 ข้อ

```
1. AIRFLOW  — ใช้พัดลมคู่ (Intake/Exhaust) แบบ Push-Pull (ควบคุมสั่งเปิด-ปิดผ่าน Relay)
2. THERMAL  — แยกเซนเซอร์ร้อน (MQ Heater) ออกจากอิเล็กทรอนิกส์ (ESP32/Power)
3. VOLUME   — ปริมาตรภายในกล่องน้อย → Response Time เร็ว
4. POSITION — ติดตั้งที่จุดที่เป็นตัวแทนของอากาศจริง (ในท่อ exhaust)
5. PROTECT  — มีระบบป้องกันไฟกระชาก, สัญญาณรบกวน, ลัดวงจร และกันฝุ่นหยาบ
```

## 3. ระบบ Airflow (Push-Pull System)

### 3.1 Active Sampling (พัดลมคู่)

การใช้พัดลม 2 ตัว (Intake + Exhaust) ร่วมกับ Relay ช่วยให้สามารถควบคุมการไหลเวียนของอากาศได้อย่างแม่นยำ:
- **Intake Fan (40mm):** เป่าอากาศตัวอย่างจากท่อเข้าสู่กล่อง
- **Exhaust Fan (40mm):** ดูดอากาศออกจากกล่องกลับสู่ท่อ (หรือทิ้ง)
- **ประโยชน์:** สามารถสั่ง ESP32 ปิดพัดลมเพื่อทำ Calibration ภายในกล่องปิด, หรือเปิดพัดลมแรงสุดเพื่อล้างห้อง (Purge) ก่อนเก็บตัวอย่างใหม่

### 3.2 ทิศทาง Airflow ภายในกล่อง

```
    AIR IN (พัดลม Intake - GPIO 25)
       ║
       ▼
    ┌──────════════════════════════════──────┐
    │         Sensor Chamber (Zone A)        │
    │   ──────────────────────────►          │
    │   อากาศไหลผ่าน sensor ทุกตัว           │
    │   จากซ้ายไปขวา (Laminar Flow)          │
    └──────════════════════════════════──────┘
                                       ║
                                       ▼
    AIR OUT (พัดลม Exhaust - GPIO 26)
```

## 4. ตำแหน่งเซนเซอร์ภายในกล่อง (Sensor Placement)

### 4.1 ลำดับการจัดวาง (ตามทิศทาง Airflow)

```
AIR IN ══►  ①        ②        ③        ④        ⑤     ══► AIR OUT
            DHT22    MQ-3     MQ-135   MQ-2     MiCS-6814
            (T/RH)   (Thinner) (VOC)   (Smoke)  (CO/NO2/NH3)
                                                  
                     ⑥ PMS5003 (วัดฝุ่น)
                     (ติดแยกชิดพัดลม ดูดฝุ่นเข้าตรงๆ)
```

**เหตุผลในการจัดลำดับ:**
- **DHT22** อยู่หน้าสุดเพื่อไม่ให้ได้รับความร้อนสะสมจาก MQ Sensors
- **MQ-3** (ทินเนอร์) อยู่ลำดับต้นๆ เพื่อ response เร็วสุด
- **MiCS-6814** ไว้หลังสุดเพราะบอบบางกว่า MQ
- **PMS5003** วางแยกชิดทางเข้าเพื่อดูดอนุภาค PM โดยตรง ไม่ผ่านสิ่งกีดขวาง

## 5. จุดติดตั้งกล่องในห้องพ่นสีฝุ่น (Installation Position)

### 5.1 หลักการเลือกจุดติดตั้ง

| เกณฑ์ | ค่ามาตรฐาน | เหตุผล |
|---|---|---|
| **หลัง Filter Bank** | ✅ ต้องอยู่หลัง filter | วัดคุณภาพอากาศ "หลังผ่านการกรอง" ก่อนปล่อยสู่ภายนอก |
| **ท่อตรง ≥ 8D** | ≥ 8 เท่าของเส้นผ่านศูนย์กลางท่อ | ให้อากาศไหลแบบ Laminar (ไม่ปั่นป่วน) ก่อนถึงจุดวัด |
| **ก่อนปากปล่อง** | ≥ 2D ก่อน stack exit | ไม่ให้ลมภายนอกรบกวน |

### 5.2 วิธีเจาะท่อติดกล่อง

1. เจาะรูบนท่อ exhaust กว้างพอดีขนาดท่อลมพัดลม 40mm หรือลดขนาดด้วยข้อต่อ
2. ต่อท่อ silicone หรือท่อลมเข้า-ออก ระหว่างท่อ exhaust กับตัวกล่อง

### 6.3 ความสูงกล่อง

```
ความสูงรวมที่ต้องการ:
  Zone A: MQ สูง 21.83mm + Standoff 5mm + ระยะห่างฝาบน 5mm = ~32mm
  Zone B: Relay สูง 18.37mm + Standoff 5mm + ระยะห่าง 5mm  = ~28mm
  Partition หนา: 3mm
  พื้นกล่อง: 3mm + ฝา: 3mm

  ※ Zone A และ B อยู่ข้างกัน (ไม่ซ้อนกัน) → ใช้ความสูงของ Zone ที่สูงที่สุด

  ความสูงภายใน = max(32, 28) = 32mm
  ความสูงกล่องรวม = 32 + 3 (พื้น) + 3 (ฝา) = ~38mm

  → กล่อง 3D Print ขนาด 220 x 150 x 40mm (ตัวกล่อง + ฝาปิด)
  → ✅ พิมพ์ได้บน Plate 22x22cm สูง 25cm (สบายมาก)
```

| แถว | อุปกรณ์ | ความสูงภายใน | จุดสำคัญ |
|---|---|---|---|
| **Row 1: MQ Sensors** | พัดลม ×2 + MQ-3 + MQ-135 + MQ-2 + MQ-8 | ~27mm (MQ สูง 21.83 + standoff 5) | เป็นช่องลมหลัก ลมเข้าฝั่งซ้าย พัดผ่าน MQ และกระจายไป Row 2 |

### 7.3 ทิศทางลมระบายอากาศ (Airflow Dynamics)

เพื่อให้เซ็นเซอร์ใน Row 2 ได้รับอากาศด้วย ต้องออกแบบทิศทางลมดังนี้:

```
        อากาศภายนอก (Ambient Air)
             │
             ▼
      ┌───────────────┐
      │ FAN IN (ดูดเข้า) │  ← สร้างแรงดันบวก (Positive Pressure)
      └──────┬────────┘
             │
 ┌───────────┴──────────────────────────────────────────┐
 │                                                      │
 │ ╔══════════════════════════════════════════════════╗ │
 │ ║ ROW 1: MQ-3, MQ-135, MQ-2, MQ-8                  ║ │  ← ลมปะทะเซ็นเซอร์ก๊าซหลัก
 │ ╚══════════════════════════════════════════════════╝ │
 │        ↓ ลมบางส่วนกระจายลงมา ↓                         │  ← ไม่มีกำแพงกั้น
 │ ╔══════════════════════════════════════════════════╗ │
 │ ║ ROW 2: DHT22, PMS5003, MiCS-6814, CCS811         ║ │  ← ลมพัดผ่านเซ็นเซอร์สภาพแวดล้อม
 │ ╚══════════════════════════════════════════════════╝ │
 │                                                      │
 └───────────┬──────────────────────────────────────────┘
             │
      ┌──────┴────────┐
      │ FAN OUT (เป่าออก)│  ← สร้างแรงดูด (Exhaust)
      └──────┬────────┘
             ▼
        ลมออกสู่ภายนอก

 ════════════ SOLID PARTITION ═════════════════════════════  ← กำแพงทึบ 100%
 [ ROW 3: ESP32, Relay, Power ] (ไม่อยู่ในระบบ Airflow หลัก)
```

> **เทคนิค:** ออกแบบให้กล่องช่วง Row 1 และ 2 ทำหน้าที่เป็น "Air Chamber" เดียวกัน ลมเข้าจากซ้ายจะเกิดความปั่นป่วน (Turbulence) และกระจายตัวไปโดนเซ็นเซอร์ทั้งหมด ก่อนจะถูกดูดออกทางขวา

## 8. ระบบจ่ายไฟ (Power System Design - 2 Paths)

> **แนวคิด:** ออกแบบให้ระบบวงจรภายในกล่องเหมือนกันทุกประการ แต่เปลี่ยนเฉพาะ "ต้นทางของไฟ" ที่ต่อเข้า DC Jack (เพื่อให้สลับระหว่างเวอร์ชั่นทดลอง และเวอร์ชั่นติดตั้งจริงโรงงานได้ทันที)

### 8.1 สถาปัตยกรรม 2 Paths

```
╔════════════════════════════════════════════════════════════════════╗
║  PATH A: ชุดทดลอง (Experimental - นำไปเดินวัดตามจุดต่างๆ)             ║

║  PATH B: ชุดจริง (Production - ติดตั้งถาวรในท่อ)                       ║
║                                                                    ║
║  🔌 220V AC ──► [Hi-Link HLK-PM01] (AC→DC 5V/9V) ──► [DC Plug]     ║
╚════════════════════════════════════════════════════════════════════╝
                                │
                                ▼
                   (เชื่อมต่อเข้า DC Jack ของกล่อง)
```

### 8.2 การออกแบบวงจรภายใน (สอดคล้องกับ wiring_design.md)
*   **Diode 1N5822:** ป้องกันการต่อขั้วผิด (Reverse Polarity) เข้า DC Jack
*   **Buck Converter 2 ตัว:** แยกราง 5V สำหรับ Heater และราง 3.3V แยกต่างหากเพื่อให้ไฟนิ่งสุด (ไม่รบกวน LDO บน ESP32)
*   **Capacitor (100uF, 100nF):** กรองสัญญาณรบกวน (Decoupling) จากฮีตเตอร์เซนเซอร์ MQ และมอเตอร์พัดลม
